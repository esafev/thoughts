RSS answers one question: what's new? Agents ask other questions, so they scrape your pages and retell your work in their own words.

What if every personal site had its own MCP? Instead of just scraping HTML, an agent could ask the site directly and get back what the author actually wrote. RSS pushes what I published. MCP lets you ask about it.

### The site answers

[WebMCP](https://github.com/webmachinelearning/webmcp) is an early proposal for this. A page registers its own tools, and the agent calls them instead of guessing from the DOM.

```js
await document.modelContext.registerTool({
  name: "about",
  description: "Who I am and what this site is",
  execute() {
    return "Vlad's notes on engineering and life";
  }
});

await document.modelContext.registerTool({
  name: "ask",
  description: "Ask a question, answered from my notes",
  inputSchema: {
    type: "object",
    properties: { question: { type: "string" } },
    required: ["question"]
  },
  execute({ question }) {
    return answerFromNotes(question);
  }
});

await document.modelContext.registerTool({
  name: "subscribe",
  description: "Get new notes as they come out",
  execute() {
    // RSS feed, email newsletter, push notifications, etc.
    return "[https://esafev.com/rss.xml](https://esafev.com/rss.xml)";
  }
});
```

### The feed points to the tools

RSS and MCP can point to each other. The `subscribe` tool returns my RSS feed, and the feed itself can list my MCP tools. RSS is already extensible through XML namespaces (that's how podcast feeds added chapters and transcripts).

```xml
<channel xmlns:mcp="[https://esafev.com/ns/mcp](https://esafev.com/ns/mcp)">
  <title>Vlad Esafev</title>
  <mcp:tool name="about">Who I am and what this site is</mcp:tool>
  <mcp:tool name="ask">Ask a question, answered from my notes</mcp:tool>
</channel>
```

### The tools need one structure

RSS worked because every feed had the same structure, so any reader could parse any site. An agent can read any tool's description and figure it out, but a feed reader can't. If `ask` meant the same thing on every site, your reader could show an "Ask" box for every blog you follow. The [IndieWeb](https://indieweb.org/) community already figured out shared conventions with Webmention and microformats.

Could we agree on a few standard tools, too?
